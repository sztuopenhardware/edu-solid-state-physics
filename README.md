# 《固体物理学》交互式 3D 教学仿真实验平台 (EP00223)

基于 **Charles Kittel《固体物理导论》（第八版）** 与 **深圳技术大学工程物理学院《固体物理学》(EP00223) 课程教学大纲** 定制开发的纯前端零构建交互式 3D 虚拟仿真实验网页平台。

- **全大纲章节覆盖**：完整覆盖大纲全部 **7 章、18 周教学进度、28 个核心教学节次**（含 38+ 个三维物理子场景）。
- **章节式下拉菜单导航**：顶部提供 **7 大章节下拉式实验菜单栏**，右侧同步配备 **“章节—案例”二级联动下拉选择器**，支持 URL 哈希直达任意实验（如 `#case=2-3`）。
- **三维实空间/倒空间 + 二维定量曲线实时联动**：每个实验均包含 WebGL 三维交互视窗、实时物理参数滑块、微观/宏观特征量计算读数、2D 联动科学绘图（色散关系、XRD 衍射谱、势能曲线、热容积分、费米分布、克勒尼西-彭尼图解法）、KaTeX 公式推导、大纲学习目标、课程思政科研前沿与随堂概念检测。
- **开箱即用发布 GitHub Pages**：纯静态相对路径架构，内置 `.nojekyll` 与自动部署工作流 `.github/workflows/deploy-pages.yml`，无需 Node.js 编译打包，本地双击 `index.html` 或上传至 GitHub 即可直接运行。

## 如何发布到 GitHub Pages

本项目已针对 GitHub Pages 完成全部静态化适配（全相对路径引用、`.nojekyll` 防拦截文件、GitHub Actions 自动部署配置）：

### 方式一：网页端直接上传（无需安装 Git 或命令行）
1. 登录 GitHub，点击右上角 **New repository** 创建一个公开仓库（例如 `solid-state-physics-3d`）。
2. 点击 **uploading an existing file**，将本工程目录下的文件（`index.html`、`css/`、`js/`、`.nojekyll`、`README.md`，**无需上传课程大纲 PDF** 若不想公开文档）拖拽上传并点击 **Commit changes**。
3. 进入仓库顶部的 **Settings** ➔ 左侧菜单 **Pages**。
4. 在 **Build and deployment** 下：
   - **Source** 选择 `Deploy from a branch`；
   - **Branch** 选择 `main`（或 `master`），目录保持 `/ (root)`，点击 **Save**。
5. 等待约 30–60 秒，刷新页面即可获得线上访问地址：`https://<你的GitHub用户名>.github.io/<仓库名>/`。

### 方式二：使用内置 GitHub Actions 自动部署
1. 将整个项目推送至 GitHub 仓库 `main` 分支。
2. 在仓库 **Settings ➔ Pages ➔ Source** 中选择 **GitHub Actions**。
3. 仓库内置的 `.github/workflows/deploy-pages.yml` 将在每次代码更新时自动完成线上构建与发布。
